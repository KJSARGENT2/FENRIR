# Fenrir

**Your viewers play the game with you.** Fenrir turns TikTok LIVE gifts, likes,
follows and chat into real actions inside Call of Duty Zombies and fifteen
other games. A rose spawns a horde. A big gift ends the round.

Everything runs on your PC. There is no server in the middle reading your
stream.

> **Open beta — 0.9.0-beta.1.** Free while it lasts, every feature unlocked,
> no card. In exchange: **it will have bugs.** Some of this has been proven by
> running it and some has not. Telling us what broke is the whole point of the
> beta.

## Download

Windows 10 or 11, 64-bit. Grab the latest build from
[Releases](../../releases), unzip it anywhere, and run `Fenrir.exe`.

Your settings, triggers and points live in `%APPDATA%\Fenrir`, separate from
the program, so updating never touches them.

**Windows will warn you about it.** Fenrir sends synthetic keystrokes and opens
network connections, which is exactly the shape of thing SmartScreen flags.
Until the build is code-signed you will see a warning. We would rather say so
here than have it surprise you.

## Read this before you install

**Accounts can be banned.** Game publishers prohibit third-party software that
changes how a game behaves, and that includes this. The risk is worst in online
and ranked modes, and lowest in offline, solo and private matches — so prefer
those. Your game account, your risk.

**This is not official and not affiliated with anyone.** Not affiliated with,
endorsed by, partnered with or approved by TikTok, Activision, or any other
publisher. Nobody has vetted this.

**It reads TikTok LIVE by unofficial means.** There is no public TikTok API for
real-time gifts, chat, likes or follows — every tool in this space reads the
stream unofficially, and TikTok's terms prohibit automated access without
written approval. Using this may breach those terms. It connects as an
anonymous viewer: it never asks for your password and cannot post as you.

The application shows the full list on first run and will not set anything up
until it is accepted.

## What you will need

- **Windows 10 or 11**, 64-bit — the same machine the game runs on
- **A free Euler Stream key** — TikTok's live data has to be signed by a third
  party. The key is free, takes a minute, and goes in Settings. Every install
  needs its own.
- **A TikTok account with LIVE** — usually 1,000 followers, though you can set
  everything up and test it with the built-in event simulator long before then
- **The game, already installed** — Fenrir finds it itself
- **OBS**, only if you want the overlay

## Games

Sixteen games and 329 mapped actions. Two are proven in a live match — Black
Ops 2 (67 actions) and Infinite Warfare (57). Six more are built and deployed
but not yet fired in a real game: Black Ops 1, Black Ops 3, World at War,
Minecraft, Valheim and 7 Days to Die. Eight are early.

## Found a bug? Got an idea?

Both are worth sending. A beta is only useful if the things that break get back
to us, and the feature requests that come out of real streams are usually
better than the ones invented at a desk.

Open an [issue](../../issues), or use the report form inside the app — it
attaches the version and the last error for you, which makes a report far more
useful than a description from memory.

## About this repository

This repo exists to host the builds. **Fenrir's source is not open** and is not
published here. Releases only.

## Redistribution

**Please do not reupload, mirror, repackage or resell Fenrir.** Install it on
machines you control and use it; if someone else wants it, send them this page
rather than the file. Redistribution without written permission is not
permitted, the licence ends automatically if it happens, and reuploads get
chased.

Beyond the legal point: a reupload is a build nobody can update, with no way to
tell whether anything was added to it. That is bad for whoever downloads it and
bad for the project.
